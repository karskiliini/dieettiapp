# GET-165 security changes (2026-10-22)

The shipped application is a static Next.js export. No server API/authentication endpoints were found in the reviewed source. Updated Next.js 16.4.2, React 19.3.1, Serwist and Drizzle dependencies, and removed the unused shadcn scaffolding CLI from application dependencies.

The native iOS app must also resolve Capacitor 8.5.3. Its exact Swift Package Manager pin and commit now match the patched npm iOS dependency. An Xcode/device build is still required before shipping the native app.

Node.js source policy is 24.22.1 (`.nvmrc` / package engines / CI). Hosting providers control their actual runtime patch rollout; these files do not prove that a deployed runtime is patched.

Dependency evidence: current lockfiles, npm audit (all + production), and the [Next.js October 14 security update](https://nextjs.org/blog/nextjs-security-update-october-14-2026). Endor risk evidence was unavailable, so no Endor SAFE verdict is claimed.
